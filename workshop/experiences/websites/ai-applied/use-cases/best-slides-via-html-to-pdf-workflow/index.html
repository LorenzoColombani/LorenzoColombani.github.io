Best slides via HTML-to-PDF workflow

By Zarja Cibej
What you'll need
Claude (or LLMs with coding capabilities)
How to do it

Creating the best presentation slides by asking LLMs to code them in HTML with full styling and interactivity, then making them downloadable as PDF. Particularly effective with Claude for creating visually appealing dashboards, reports, and presentations with better design control than native slide generation.
