Messages (icône verte 💬) - Pour iPhone

Mail (icône bleue 📧) - Pour email
💡 Astuce: Si la personne a un iPhone, utilisez Messages. Sinon, utilisez WhatsApp.
💬
Messages (iMessage)
Icône: Bulle verte sur fond blanc
Pour: Autres iPhone uniquement
Bulles bleues: Message envoyé à un iPhone
Bulles vertes: SMS normal (payant)
Gratuit: Oui, avec WiFi ou données
💚
WhatsApp
Icône: Téléphone blanc sur fond vert
Pour: Tous les téléphones
Bulles vertes: Vos messages
Bulles blanches: Messages reçus
Gratuit: Oui, avec WiFi ou données
⚠️ Attention: Les deux apps se ressemblent mais sont complètement séparées. Un message envoyé dans Messages n'apparaît pas dans WhatsApp et vice-versa.
💡 Comment savoir laquelle utiliser?
Demandez à la personne: "Tu préfères Messages ou WhatsApp?" La plupart des gens ont une préférence.
1
Ouvrir Mail
Touchez l'icône Mail 📧 (enveloppe bleue et blanche)
🚨 Signes d'une ARNAQUE:
• Demande urgente d'argent
• Menaces (compte bloqué, amende...)
• Fautes d'orthographe
• Adresse email bizarre (xyz123@...)
• Liens suspects
• "Félicitations, vous avez gagné!"
✅ Email LÉGITIME:
• Adresse officielle (ex: service@laposte.fr)
• Pas de demande d'argent surprise
• Français correct
• Vous attendiez ce message
⚠️
En cas de doute
NE CLIQUEZ PAS sur les liens!
1. Faites une capture d'écran
2. Envoyez-la à un proche de confiance
3. Supprimez le message suspect

❌
"Stockage iPhone presque plein"
Solution:
1. Réglages → Général → Stockage iPhone
2. Touchez "Photos"
3. "Optimiser le stockage iPhone"
4. Supprimer anciennes conversations Messages
❌
"Aucune connexion Internet"
Solution:
1. Vérifiez le WiFi (Réglages → Wi-Fi)
2. Est-ce que c'est activé (vert)?
3. Êtes-vous connecté à votre réseau?
4. Sinon: éteignez/rallumez le WiFi
❌
"Identifiant Apple - Vérification requise"
Solution:
1. C'est normal après mise à jour
2. Entrez votre mot de passe Apple
3. Si oublié: "Mot de passe oublié?"
4. Suivez les instructions
⚠️ IMPORTANT: Si un message demande votre mot de passe par email ou SMS, c'est une ARNAQUE! Apple ne demande jamais ça.
1
Son disparu?
• Boutons volume sur le côté gauche
• Appuyez sur celui du haut (+)
• Vérifiez l'interrupteur silence (au-dessus des boutons)
2
Écran trop sombre/clair?
• Balayez du haut-droite vers le bas
• Ajustez la barre de luminosité ☀️
• Ou: Réglages → Luminosité et affichage
3
Texte trop petit?
Réglages → Affichage et luminosité → Taille du texte
Glissez le curseur vers la droite pour agrandir
4
Apps disparues?
• Balayez vers le bas sur l'écran d'accueil
• Tapez le nom de l'app dans la recherche
• Elle est peut-être dans la Bibliothèque d'apps (balayez tout à gauche)
1
Retrouver un mot de passe
Réglages → Mots de passe
• Utilisez Face ID ou votre code
• Recherchez le site/app
• Touchez pour voir le mot de passe
💡 Remplissage automatique:
iOS 26 peut remplir vos mots de passe automatiquement. Quand vous voyez "Remplir le mot de passe" au-dessus du clavier, touchez-le!
2
Mot de passe oublié?
Sur la plupart des sites:
1. Touchez "Mot de passe oublié?"
2. Entrez votre email
3. Vérifiez vos emails
4. Suivez le lien pour réinitialiser
🔐 Sécurité:
• Ne donnez JAMAIS vos mots de passe par téléphone
• Personne de légitime ne les demandera
• Même pas Apple ou votre banque!
