TVA Case File

The concept

In Loki, the TVA prunes anyone who steps off their assigned timeline. The case file takes the joke seriously: to a filing system, a person who has been a lawyer, a mediator, a teacher and a builder is a series of deviations. The sequence files them one by one and lets a single timeline through.

Art direction and typography

Paper as a printed object — cover, stamps, margin notes — in a gold palette, with type sized to read at phone distance. Every frame is a document first and a shot second.

Motion and pacing

One continuous cut. No scrubbing, no chapter menu: it is meant to be watched, not browsed.

The browser build

It runs in the browser on desktop and on the phone, and the phone cut was tuned on the device, not in an emulator. Assets are versioned so a stale build can never play; every publish passes a smoke test first.

What it proves

This is the craft proof of the portfolio — a method you can watch. The same discipline, a spec and a definition of done before anything ships, is how the tools on this site get built.
